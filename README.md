# PHL5 - Siber Güvenlik & OSINT Aracı

Windows, Linux ve macOS'ta çalışan, modüler bir siber güvenlik ve OSINT aracı.

## 📦 Özellikler
- E-posta OSINT (MX sorgu, HaveIBeenPwned)
- Kullanıcı Adı OSINT (8+ platform)
- IP OSINT (konum, ISP, koordinat)
- Domain WHOIS sorgulama
- Telefon numarası analizi
- Port tarama
- Şifre gücü testi
- Yabancı IP algılama
- Bilgisayar güvenlik testi (Windows)
